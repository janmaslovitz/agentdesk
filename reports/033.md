## Worker summary

I added `python -m agentdesk serve` and the `agentdesk-server` entry point, and the full suite passes (391 tests, including 10 new ones in `tests/test_serve.py`). I only ran it on Windows, so nothing was run on Debian itself.

- **Server:** the new `agentdesk/serve.py` runs the dashboard with no window, tray or browser, and the serve path never imports `pywebview` or `pystray`. It takes `--host`, `--port` (0 picks a free port), `--data`, `--allowed-host` (repeatable), `--auth-token-file`, `--trust-proxy-auth` and `--pid-file`.
- **Startup:** it logs to stdout and shuts down cleanly on SIGTERM and SIGINT. `--data` sets `AGENTDESK_HOME` before `core` is imported. The tests start it with `--port 0` both in-process and as `python -m agentdesk serve`, and a request to `/api/version` gets an answer.
- **Public bind:** binding a non-loopback address fails with a clear message unless `--auth-token-file` is given. `--trust-proxy-auth` on its own also fails. The token must be at least 16 characters.
- **Host/Origin and token:** `server.py` now has a `Guard` class. Every GET and POST must carry an allowed Host, and every POST with an Origin must have an allowed one. By default only loopback names are allowed, so existing local behaviour is unchanged. With a token configured, every request must send it in `X-AgentDesk-Gateway-Token`, compared in constant time.
- **Allowed names:** these come from the bind address plus `--allowed-host`. A foreign Origin or Host gets 403 and a missing or wrong token gets 401. Binding `0.0.0.0` allows loopback only until you add `--allowed-host` for the address you actually browse to.
- **Linux audit:** the Windows-only calls in `core.py`, `server.py` and `hygiene.py` (`creationflags`, `taskkill`, `ctypes`, `os.startfile`, `LOCALAPPDATA`) were already behind `os.name` or `sys.platform` checks. The one fix was "Open build folder", which failed on a machine with no `xdg-open`; it now returns a message instead.
- **Other:** I added a small `pyproject.toml` that only defines the `agentdesk-server` script, and an Unreleased entry in `CHANGELOG.md`.

The `Origin` check now also accepts `https` origins when the host is allowed. Before, only `http` loopback origins passed.

NOTES:
- Gateway auth: instances started with `--auth-token-file` need the header `X-AgentDesk-Gateway-Token` on every request. The gateway must also be listed via `--allowed-host`, since it forwards the browser's Host and Origin.
- `server.GUARD` is the module-level `Guard` (default is loopback only); tests that change it must restore it.
- `serve.py` must not import `core` until after `--data` is applied (`serve.prescan_data`).
