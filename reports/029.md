## Worker summary

Each task's tool calls are now counted and saved as `tool_stats` in its state.json entry. The full suite passes (343 tests). A mocked run in the new test shows `tool_stats` appearing in state.json. I didn't run a real worker, and I didn't run a formatter.

- **Counting:** the existing `Activity` class in `agentdesk/core.py` now counts every tool call by name. Calls named `mcp__<server>__<tool>` are also grouped per server.
- **`tool_stats` and `runs_stats`:** when a worker run finishes, its counts are added to the task's `tool_stats` (`total`, `by_tool`, `mcp`). Each run is also appended to `runs_stats` with its own counts plus `turns`, `cost_usd`, `duration_ms`, `tier` and `attempt`. Totals accumulate across retries and repeated runs of the same task.
- **Already stored:** turns and cost were already saved per run. I only added duration.
- **Report line:** `reports/<id>.md` gets a `Tools: N calls (top tools); MCP: server n` line, or `MCP: none`.
- **Errors:** any error in the stats code is swallowed, and the summary-line failure is logged; a stats error can't break a run.
- **Router calls:** the router's own tool calls are not counted, only the worker's.
- **UI:** I added nothing to the UI.
- **Tests and changelog:** `tests/test_tool_stats.py` covers counting, MCP grouping and accumulation. I added an Unreleased entry to `CHANGELOG.md`.
