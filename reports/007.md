## Worker summary

AgentDesk now keeps one usage reading per account, shows it with source and age, and refuses or stops runs by the pause rules. The full suite passes (89 tests).

**Automatic source:** only the SDK `RateLimitEvent` (`rate_limit_info.utilization`) is used. I did not find a headless alternative. The Claude CLI `/usage` command is interactive, and the statusline data only exists inside an interactive session. The only other route I know of is the OAuth usage endpoint, which needs your credentials, so I left it out. The SDK value is often null, so in practice the manual field does most of the work. I did not test the SDK event against a live account here, only with fake events.

- **Reading (`core.py`):** each account's `.json` file gains a `reading` entry with the percentage, time and source (`sdk` or `manual`). Old files without it still load, and a null reading counts as no reading.
- **Pause rules:** the newest reading is checked before each task and before each attempt.
  - **No reading, or older than `usage_max_age_min`:** refuses with "usage unknown — enter it under Accounts".
  - **At or above `pause_at_utilization`:** stops with "usage limit N% reached the pause threshold".
- **Per-run capture:** every router run and worker attempt in `state.json` gets `usage_before`, `usage_after` and `usage_used_pct`, in percent points. A run shows null ("unknown") when no newer reading arrived during it, so a manual-only account never shows a false 0.
- **Manual value:** a new `POST /api/accounts/<name>/usage` endpoint takes a percent from 0 to 100 and stores it as `source = "manual"`.
- **Settings:** `[limits] usage_max_age_min = 30` is added to `data/settings.toml` (and the built-in defaults), with the existing values untouched.
- **Dashboard:**
  - **Account row:** shows the percentage, source and age, plus a "Current usage: [ ] %" field with Save.
  - **Gauge:** shows the same, or "unknown" when there is no fresh reading.
  - **Tasks:** each task shows "used about X% of your window", or "unknown". The run table has a new Window column.
  - **Tier averages:** a line above the task list shows "standard tasks average Y%".
- **Docs and tests:** the README Accounts section covers all of this. The new `tests/test_usage.py` covers null, stale, manual, threshold stop at 0.90, the run deltas, a worker attempt recording usage, and the tier averages.

The pause check now also runs at the start of each attempt. The old in-run utilization tracker in `Meter` is gone, so the pause now follows the saved reading.

I did not run a formatter, and I did not look at the dashboard in a browser.

NOTES:
- Account json `reading` = {utilization (0–1), at, source}; run entries `usage_*` are percent points; `core.usage_gate(acct)` is the pause check.
- Automatic source: only the SDK RateLimitEvent, often null; the manual value is the reliable fallback.
