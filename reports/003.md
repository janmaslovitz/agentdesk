**Choices you may want to change:**
- **Coworker:** it can be selected and is saved, but behaves as the Assistant, with a note in the chat header.
- **`plan_task` needs approval** like the run tools, because it starts a router process that costs money.
- **"Always allow" only appears on shell cards.** For run/stop cards it counts as Allow once.
- **Allow-list is stricter than prefix matching.** A command only runs without a card if it is one plain command. Anything containing `; & | < > ( ) { } $`, a backtick or a newline always asks, as does anything the `[guard] deny` list matches. Without this, an allowed `git status` would also let `git status && rm -rf …` through, and PowerShell runs whatever is inside `(...)` in an argument.
- **Suggested prefixes can be broad.** Haiku tends to write `git -C "<path>" log`, so the suggested prefix becomes just `git`. You can edit it in the card before pressing Always allow, but `git` alone would allow every git subcommand not on the guard deny list.
- **Long waits:** a chat request can now wait up to 30 minutes for answers (it was 5 minutes before). "New chat" and switching modes deny any open cards and interrupt the session.
- **Settings:** the default settings now use `[chat.assistant] model = "haiku"`. An old `[chat] model` entry is still honoured.

**Main changes:**
- `agentdesk/core.py`: helpers that read and write `chat_mode` and `[chat] allowed_commands` in `project.toml`, plus prefix matching, prefix suggestion and the settings lookup. The worker pipeline is untouched.
