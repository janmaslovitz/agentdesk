**What changed**
- **Data rule** (`core.py`): `AGENTDESK_HOME` wins. A frozen program uses `data` next to the `.exe` only if it already exists there, otherwise `%LOCALAPPDATA%\AgentDesk`. Running from source is unchanged, so `AgentDesk.cmd` still works. `server.py` line 61 still passes `core.DATA` to the child processes, which stays correct. A new test in `tests/test_datahome.py` covers these rules.
- **Tray in the build:** `build_exe.ps1` now installs `requirements-tray.txt`, and `agentdesk.spec` lists `pystray._win32` as a hidden import. I did not check that the tray shows in the built program.
- **`installer/AgentDesk.iss`:**
  - Install and folder: `PrivilegesRequired=admin`, default folder `{autopf}\AgentDesk`, folder page shown. The dialog or `/CURRENTUSER` lets the user install for themselves without elevation.
  - Shortcuts: a Start menu entry, plus a desktop icon that is unchecked by default. Both start `AgentDesk.exe` with no arguments.
  - Uninstall: it asks "also remove my data" and deletes `%LOCALAPPDATA%\AgentDesk` only on Yes. A silent uninstall keeps the data unless `/REMOVEDATA` is given. Nothing touches a `data\` folder next to the exe.
  - Missing tools: it checks for the Claude Code CLI and WebView2, shows a message with a download link, and carries on. I wrote this check but did not exercise it.
- **`build_installer.ps1`:** runs `build_exe.ps1`, refuses to continue if `dist\AgentDesk` holds `data`, `accounts`, `.venv`, `worktrees`, `__pycache__` or `.env`, then runs `ISCC.exe`. I installed Inno Setup 6.7.3 per-user with winget to do this.
- **`README.md`:** new "Build the installer" and "Install" sections, covering install, uninstall and where data goes. I also corrected the data-location line from 008.

**Actually tested**
- Full build via `build_installer.ps1`.
- Non-elevated silent install with `/CURRENTUSER /DIR=<temp>`. It put 351 entries (325 MB) in the folder, with no `data`, `accounts`, `.venv`, `worktrees`, `__pycache__` or `.env`, and no desktop icon. It created the Start menu shortcut (pointing at the installed `AgentDesk.exe`) and the Apps & features registry entry.
- With a temp `LOCALAPPDATA`, I ran the installed exe with `add-project`. Data went to `<LOCALAPPDATA>\AgentDesk` and no `data\` appeared next to the exe.

- After a reinstall, the `data\` next to the exe was still there. Uninstalling with `/REMOVEDATA` deleted `%LOCALAPPDATA%\AgentDesk` and left the `data\` next to the exe alone.
