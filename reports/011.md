## Brief

Goal: in AgentDesk (Windows first), clicking the window's X hides the pywebview window to a system tray icon instead of ending it. Tray click or "Open" shows the same window with the same state. Tray "Quit" closes the window and stops the server, the same as the dashboard Quit button. Closing the window must never stop runs.

Relevant code:
- agentdesk/server.py:866-899 `open_window(url)`: creates the window, saves geometry in `closed()` (lines 882-889), calls `webview.start()`. Returns False on any failure, and `main` then opens the browser.
- agentdesk/server.py:902-934 `main()`: starts `ThreadingHTTPServer` on a daemon thread, then `open_window` or the browser, then `while thread.is_alive(): join(0.5)`. `finally` shuts the server down and removes the pid file.
- server.py ~855-863 is the log helper (`log_error`, writes `core.DATA/agentdesk.log`). Use it for the tray-fallback line.
- agentdesk/__main__.py:133-155: the `dashboard` entry point calls `server.main(...)`. `stop` is `cmd_stop` (line 86), which kills the pid from `data/dashboard.pid`. Don't change its semantics.
- README.md lines 16-19 ("Start" section): add one sentence on tray behaviour and Quit. Make it match the code exactly.
- requirements.txt: pywebview>=5.0 is there. Add pystray and Pillow as optional (for example a `requirements-tray.txt` or an extras note). Don't break the base install.

## Worker summary

Closing the window now hides it to a tray icon when pystray and Pillow are installed. I only checked that the tray starts and the fallback logs; I did not check hide, show or Quit with a real window.

**What I changed**
- **`agentdesk/server.py`:**
  - A new `start_tray` builds the tray icon with "Open" and "Quit" and starts it on its own thread, so `webview.start()` stays on the main thread.
  - `open_window` takes `tray=True` and cancels the close event and hides the window.
  - "Open" or a click on the icon shows and restores the window.
  - Tray "Quit" sets a quit flag, closes the window and stops the icon, and the server then shuts down.
  - If the tray can't start, `agentdesk.log` gets one line with the reason, and closing ends the window as before.
- **Geometry saving:** I didn't touch it.
- **`main()`:** it calls `open_window(url, tray=True)` and also exits its wait loop when Quit is pressed. The path where a dashboard is already running still opens a plain window with no tray.
- **`requirements-tray.txt`:** new file with `pystray>=0.19` and `Pillow>=10`. `requirements.txt` is unchanged, so the base install is unaffected.
- **`README.md`:** the Start section now describes the tray, "Open", "Quit" and the fallback.

**Done-checks**
- **Tests:** all 82 tests pass, run with a temporary `AGENTDESK_HOME`.
- **Tray starts:** with pystray and Pillow installed, `start_tray` returns a working Windows icon.
- **Fallback log line:** with pystray blocked, `start_tray` returned None and logged the "no tray icon, closing the window will end it" line.
- **Not verified:** a real GUI session. That covers hiding the window, showing it with the same state, a run surviving the hide, and tray Quit followed by `stop` reporting nothing running. The end-to-end `pythonw` check is also still open.

**Things to know**
- There is no Quit button in the dashboard code (no match for "quit" in any non-README file), so tray Quit just closes the window and lets `main()` shut the server down. The README's earlier "Quit" wording I left alone apart from the new sentence.
- The tray's Quit stops only the server, so detached runs keep going.

NOTES:
- No dashboard Quit button exists in the code; `QUIT` (a threading.Event in server.py) is what tray Quit sets, and `main()` watches it.
- Tray is optional (`requirements-tray.txt`) and only used in the server-owning process; a full pytest run takes about 30s.
