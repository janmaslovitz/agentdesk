The working indicator is in place in `agentdesk/web/index.html`. `tests/test_chat.py` passes (24 tests), and the page's inline script parses without errors.

**What changed**
- **CSS:** added `.working` and `.working i` (three dots with a staggered `working` keyframe pulse). A `@media (prefers-reduced-motion: reduce)` rule turns the animation off and leaves the dots static.
- **`send()`:** the placeholder is now an empty assistant bubble holding three dots and a `working… Ns` label. A 1 s `setInterval` updates the label from a start timestamp.

- **Project switch:** the timer checks `forProject !== cur || !wait.isConnected` on each tick and clears itself. `refresh()` (line ~394) empties `#msgs` when the project changes, so the bubble detaches and the timer stops on its next tick. I did not add a separate clear to `refresh()`.
