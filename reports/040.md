# 040: Split builds: desktop App vs headless Server

Branch `auto/040` at 8ed96e6; tiers standard.

## Brief

Goal: AgentDesk ships as two separate products sharing one core: (A) desktop App (Windows: window, tray, AgentDesk.exe + installer) and (B) headless Server (Linux: serve.py + agentdesk/gateway + console tool + deb/systemd). Today both live in one package and one dependency set.
Do (check what earlier tasks 033-039 already did, only add what is missing):
1. pyproject.toml: base dependencies = core only; extras `app` (pywebview, tray libs from requirements*.txt) and `server`. Headless install must not pull GUI libs. Keep `pip install .` working.
2. Headless entry points (serve.py, gateway, console tool) must import without any GUI module. Add a test that imports them with GUI modules blocked (sys.modules poisoning) and passes.
3. Build scripts: build_exe.ps1 / build_installer.ps1 / agentdesk.spec build only the App; packaging/debian/build_deb.py builds only the Server. Make sure the PyInstaller spec excludes gateway/server-only code that is not needed, and the deb excludes GUI code/deps. Separate artifact names and version stamps (AgentDesk-Setup-x.y.z.exe, agentdesk-server_x.y.z_*.deb).
4. release.ps1 and any CI: separate targets (app, server, both), clear usage text.
5. README/CHANGELOG: short section 'Two products' explaining which to use when.
Constraints: no behaviour change at runtime; run `pytest tests` (not bare pytest) and keep all tests green. Done when both build paths are independent and the new import-isolation test passes.

## Worker summary

The App and the Server now build independently, and `pytest tests` passes (524 passed, 5 skipped). I didn't run the PyInstaller, Inno Setup or `dpkg-deb` builds here. The only packaging check is the staged-`.deb` test.

- **Dependencies:** `pyproject.toml` base dependencies are now the core only (`claude-agent-sdk`). The extras are `app` (pywebview, pystray, Pillow), `server` (empty, since the gateway is stdlib-only) and `build` (PyInstaller). I added `requirements-core.txt`, and `requirements.txt` now pulls it in plus pywebview. I didn't run `pip install .`; the test compares `pyproject.toml` with the requirements files.
- **Import isolation:** serve, the gateway modules, the console tool and `server` already imported no GUI module at top level, so no code change was needed. `tests/test_product_split.py` runs a subprocess with `webview`, `pystray`, `PIL`, `tkinter` and `gi` blocked and imports them all. It also checks the extras against the requirements files, the spec excludes, and a staged `.deb`.
- **App build:** `agentdesk.spec` now excludes `agentdesk.gateway`, `agentdesk.serve` and `agentdesk.storage`. That is the one runtime change: `AgentDesk.exe serve`, `gateway` and `server` now exit with a message pointing to the `.deb`. `build_exe.ps1` and `build_installer.ps1` are labelled App-only. The usage text in `build_exe.ps1` now says `-DesktopShortcut`, matching the actual switch (it said `-NoDesktopShortcut`).
- **Server build:** `build_deb.py` takes its requirements from `requirements-core.txt` and drops `.ico`/`.icns` files and `_buildinfo.py` from the package. It still produces `agentdesk-server_x.y.z_all.deb`, and the installer keeps `AgentDesk-Setup-x.y.z.exe`.
- **Release:** `release.ps1` has `-Target app|server|both` (default `app`) and fuller usage text. The server target builds the `.deb` with `dpkg-deb` if it's available, otherwise through WSL. If neither exists it warns and leaves it to CI. In `release.yml` I labelled the two jobs by product and added a step that runs the isolation test in the `deb` job with core dependencies only.
- **Docs:** README has a "Two products" section with a comparison table, and CHANGELOG has an entry under Unreleased.

NOTES:
- Core deps live in `requirements-core.txt` and `pyproject.toml`; a test keeps them in step. GUI deps go only in `requirements.txt`, `requirements-tray.txt` and the `app` extra.
- Server-only modules (`gateway`, `serve`, `storage`) are excluded from the PyInstaller spec via `SERVER_ONLY`. A new server-only module must be added there, and the `.deb` must not ship GUI assets.
- Heredocs in the Bash tool mangle `\b` into a backspace character; use the Edit tool for Windows paths.
