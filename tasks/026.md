Goal: let a project give its workers extra MCP servers (first use: code-graph-mcp for Sintec.PDF). Files: agentdesk/core.py options() (~1593), work() (~1746), route() (~1701); project.toml parsing (Project.cfg).

Add optional config in project.toml, e.g.
[mcp.code-graph]
command = "npx"
args = ["-y", "@sdsrs/code-graph"]
env = { CODE_GRAPH_NO_AUTO_UPDATE = "1", CODE_GRAPH_DISABLE_MODEL_DOWNLOAD = "1" }
enabled = true
roles = ["worker", "router"]   # default worker only

options() passes them as ClaudeAgentOptions(mcp_servers={name: {"type":"stdio","command":...,"args":[...],"env":{...}}}) for the chosen roles, and adds `mcp__<name>__*` to allowed_tools where an allowlist is set (router allows only Read/Grep/Glob today — add the MCP tools only if the role lists it). On Windows, `npx` must be resolved to npx.cmd (shutil.which) when spawned. Workers run with can_use_tool=guard(wt): make sure the guard permits the configured mcp tools (read-only graph queries) without opening anything else. Invalid/missing config must never break a run: skip with a log line. The server's cwd must be the worktree (the index lives in .code-graph/ in the repo root — the worker's worktree; make sure worktree creation doesn't commit it: the tool writes the ignore rule to .git/info/exclude by default, which is per-repo; verify it also applies in linked worktrees, otherwise add `.code-graph/` handling in the worker gate/commit step so it's never committed).

Add the Mcp section to docs (README/CHANGELOG short note) and tests for config → options conversion (no network). `pytest tests` (not bare pytest) must pass. Do NOT edit any project's own project.toml; the coworker will enable it for Sintec.PDF.
