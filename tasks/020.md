Goal: while the chat assistant is working on a reply, the user should clearly see that it is busy and not frozen.

What's wrong today: in send() (agentdesk/web/index.html, around lines 492-499) the placeholder bubble is a static "…" text. It looks the same whether the request just started or has been running for minutes. The send button is only disabled, with no other feedback.

Where:
- agentdesk/web/index.html: send() and addMsg(). Add a small animated indicator (e.g. three pulsing dots via CSS keyframes, class names following the existing style) inside the placeholder bubble, plus an elapsed-seconds counter ("working… 12s") updated once per second.
- Clear the interval/timer when the reply arrives or the request fails, so no timer keeps running after wait.remove().
- If the project switches while waiting (forProject !== cur), the indicator must not stay on screen in the new project view.
- Do not change agentdesk/server.py or the chat API.

Constraints:
- No new dependencies; plain HTML/CSS/JS in the existing file.
- Keep existing behaviour: the reply still replaces the placeholder, the error text still shows on failure, the send button stays disabled while waiting.
- Respect prefers-reduced-motion for the animation (static dots or no animation).

Done when:
- Sending a message shows animated dots and a running seconds counter in the assistant bubble.
- When the reply arrives, the indicator disappears and the reply is shown, with no leftover timers.
- On an API error, the indicator is replaced by the error text.
- Existing tests in tests/test_chat.py still pass.
