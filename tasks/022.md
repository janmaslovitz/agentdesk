Rework the task detail panel (agentdesk/web/index.html showDetail, and the /api/p/<slug>/task/<id> endpoint in agentdesk/server.py as needed). Clicking a task must show, in this order, as clear sections:
1. Prompt: the task text (tasks/<id>.md body) as the user/planner wrote it.
2. Orchestrator handoff: what the router/orchestrator decided and to whom: tier, model, effort, the router's reasoning (`why`), the brief it gave the worker, dependencies, branch/worktree, and each run (who/which model got it, when, attempt).
3. What the agent did: a readable timeline of the worker's run (tool calls, files touched, commands, checks run, turns, tokens, cost, failures/retries). Source: run logs in agentdesk.log / runner.log / stored run transcript if any; if the data is not recorded today, start recording a compact per-run activity log (data per task, e.g. runs/<id>.jsonl) and show it.
4. Agent report: reports/<id>.md rendered (how and what it did, result, commit).
Keep sections collapsible (done tasks: report open, others collapsed), do not re-render the panel when nothing changed (no scroll/collapse reset on polling), show sensible empty states ("not started yet"). Add/adjust tests; run `pytest tests`.
