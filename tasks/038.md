Make the headless server survive crashes, hangs and reboots without a human. Check what parts 1-4 already did and do only what is missing.
1. systemd watchdog: gateway and every instance call sd_notify (pure-python via NOTIFY_SOCKET, no new dependency; no-op when not under systemd): READY=1 after listening, WATCHDOG=1 pings from a thread that only pings when an in-process self-check passes (request loop answers a loopback /gateway/health, user store readable, disk not full). Unit: WatchdogSec=60, Restart=always, RestartSec=3, StartLimitIntervalSec generous, Type=notify (or notify with fallback), After=network-online.target, enabled at install. A hung (not crashed) gateway must get restarted.
2. Boot / crash recovery at gateway and instance start: remove stale pid files and lock files whose process is gone (check pid AND start time/cmdline so a reused pid is not trusted), mark tasks left in `working`/running state with no live process as crashed via the existing core.recover_stale, retry per the auto-runner settings, finish half-written data files (existing corrupt-file fallback), prune orphan git worktrees (`git worktree prune`) and half-created ones. Chats that were mid-turn at the crash show "interrupted by a restart" instead of "working".
3. Auto-resume: after a reboot the auto-runner continues queues of users whose instances were active before (record "was active" in the user's data; instances start lazily or eagerly per config `autostart_instances = true`), respecting the usage-limit pause.
4. Health: `/gateway/health` (no auth, no secrets) returns ok + version + per-instance up/down counts; `agentdesk-server status` and `doctor` show them; a stuck child process guard: kill claude/git children of a run that exceeded a hard timeout (configurable) or whose parent died (process groups, kill on instance shutdown); disk-space guard (refuse to start runs under N GB free, log loudly).
5. Logs: rotate agentdesk.log, runner.log, audit.log, gateway/instance logs by size (keep N), so the disk never fills; journald for the service output.
6. Graceful shutdown on SIGTERM (systemd stop/reboot): stop accepting, let running workers finish their current step or checkpoint them so recovery in 2 works; time-bounded (TimeoutStopSec).
Tests: simulate stale pid/lock files, orphan `working` tasks, a hung self-check (watchdog not pinged), log rotation, SIGTERM handling where portable. CHANGELOG under Unreleased. Document in docs/SERVER.md (reboot behaviour, how to check `systemctl status`, `journalctl -u agentdesk-server`). Do not bump the version.
