Follow-up from the security review of the gateway (agentdesk/gateway/). Check first what part 3 (admin cabinet) already did and do only what is missing:
(a) per-user `projects` and `accounts` assignments are stored but the proxy/instances do NOT enforce them: a user's instance must only see/use the Claude accounts assigned to it (write only those into that instance's settings.toml; never other users' keys or secrets), and project assignments must match what exists in the user's home.
(b) POSIX: chmod 0700 on every `users/<name>` folder and on server-home secrets (users.json, secret/token files, audit.log 0600).
(c) users.json writes are safe across processes (CLI + gateway): a file lock (fcntl on POSIX, msvcrt on Windows) around load-modify-save.
(d) after `_spawn` of an instance (instances.py), verify the listener on the chosen port really is our child before routing traffic or sending the gateway token: child pid alive AND an authenticated request with the gateway token answers as AgentDesk (e.g. /api/busy); otherwise kill/retry on another port.
(e) a login throttle regression test with parallel guesses (threads) proving at most max_failures password checks pass the throttle.
Tests: pytest tests. CHANGELOG under Unreleased. Do not bump the version.
