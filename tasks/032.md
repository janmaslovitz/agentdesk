Goal: redo the Export and Import dialogs (agentdesk/web/index.html: #dExport, #dImport; JS exportZip/exportGit/importProject; backend core.export_to_git / import_project, server.py import_route and export route).

1. NEW: export the project to GitHub as a SEPARATE BRANCH of the project's own repo (e.g. `agentdesk-export/<slug>`), not into the working branch. Implement in core (e.g. export_to_branch): use a temporary git worktree or plumbing so the user's checkout/current branch and uncommitted changes are never touched; commit the export files (same content as export_files/_manifest, under .agentdesk/ or at the branch root - pick one, document it) onto that branch, create or update it (fast-forward only, never force). Optional push of that branch to `origin` (-u), only with confirm=true like the existing git push flow. Report branch name, commit, pushed or not. Importing from that branch (clone URL + branch) should work too if cheap. Keep the existing .zip export and the commit-into-.agentdesk mode working (maybe as a mode selector: Zip / Git folder / GitHub branch).
2. REPLACE manual path typing with a Browse button (native folder/file picker via the desktop window if available - check how the app window is created, e.g. pywebview create_file_dialog through a js_api or a server endpoint; fall back to the plain text field when no native window, e.g. in a browser). Apply to: export config repo folder, import source folder, import repo folder. Keep the field editable.
3. FIX BUG: the placeholders `C:\path\to\repo` are written unescaped in HTML, so `\t` and `\r` became real tab/newline characters (see lines ~184-196). Use plain placeholders without backslashes problems.
4. FIX alignment/layout: consistent label/input/button widths, group sections with headings and spacing, input+Browse on one row, buttons aligned right in a footer row, no overflow, readable status message area. Check both dialogs at the app's default window size and a narrow one, in light/dark if the theme supports it.

Constraints: no new heavy dependencies; Windows first. Add tests in tests/test_export_import.py for the branch export (checkout and current branch untouched, no force, repeat export with no changes makes no commit). Run `pytest tests` (not bare pytest). Done = tests pass, dialogs reworked, summary of what changed in the report.
