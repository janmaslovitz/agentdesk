Goal: cheaper/faster orchestrator, no behaviour change. Files: agentdesk/core.py (and __main__.py/server.py if imports live there).

1. route() (core.py ~1701) is called for every task even when the task file sets `tier` (result discarded at ~1740). If task.tier in TIER_ORDER, skip the model call and return {"tier": task.tier, "why": "set in the task file", "brief": task.body}. Keep the 'routed' activity event. Also apply in the plan-only path (~1901).
2. load_tasks(p) re-reads/parses all tasks/*.md on each call. Add a cache keyed by (path, mtime_ns, size) per file (or dir mtime + file stats) so unchanged files aren't re-parsed; invalidate when files change/added/removed (add_task must be visible immediately). Return fresh Task objects/copies so callers that mutate task.crates don't pollute the cache.
3. Cold start is ~3.6s mostly from importing claude_agent_sdk (and mcp) before the window opens. Defer these imports until first needed (inside functions that actually use the SDK, or a lazy accessor), so the dashboard window/server comes up first. Make sure type names used in isinstance checks still work (import lazily inside those functions). Don't break PyInstaller (agentdesk.spec hidden imports stay valid).

Constraints: run `pytest tests` (not bare pytest); all tests must pass (174 currently); add tests for 1 and 2. Report cold-start time before/after (python -X importtime or simple timing of import agentdesk.__main__ to server ready).
